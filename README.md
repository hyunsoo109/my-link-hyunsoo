# my-link-hyunsoo

> Next.js와 Tailwind CSS로 제작한 조현수의 개인 프로필 및 링크 인 바이오(Link-in-bio) 웹 애플리케이션입니다.

## 📌 프로젝트 소개
- 개인 프로필, 소개글 및 링크들을 깔끔하고 직관적으로 전달할 수 있는 반응형 웹페이지입니다.
- 깔끔한 카드형 UI와 다크 모드 스타일이 적용되어 있습니다.

## 🛠 기술 스택
- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Library:** [React](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)

## 🚀 시작하기

개발 서버 실행:

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속하여 결과를 확인할 수 있습니다.
